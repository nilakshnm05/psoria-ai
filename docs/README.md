# PsoriaAI Documentation

Welcome to the official documentation for **PsoriaAI**.

This folder documents the **product vision**, **engineering philosophy**, **roadmap**, and **architectural decisions** behind the project.

The goal is to explain **why** the project is built the way it is—not just **how** it is implemented.

Records important technical decisions made during development.

Each decision includes:

- Decision

Architecture Decision Records (ADRs) help document *why* certain approaches were chosen and provide context for future contributors.

# Documentation Philosophy

This documentation follows four principles:

1. Explain the reasoning behind decisions.
2. Keep documents up to date as the project evolves.
3. Prefer clarity over unnecessary detail.
4. Treat documentation as part of the product, not an afterthought.
