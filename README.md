# PsoriaAI

An AI-powered psoriasis companion built as a production-style frontend engineering project.

## Mission

Help people manage psoriasis through the Triple A Strategy:

- Availability
- Accessibility
- Affordability

---

## Goals

- Build a portfolio-quality application.
- Learn frontend engineering from first principles.
- Practice professional Git workflows.
- Evolve into a real-world product.
